# TaskNest 📝

**TaskNest** es una aplicación de escritorio moderna y eficiente diseñada para la gestión de notas, construida sobre tecnologías web de vanguardia y el robusto framework Tauri.

## 🚀 Sobre el proyecto

TaskNest permite a los usuarios organizar sus pensamientos y tareas de manera sencilla, ofreciendo una experiencia fluida con soporte para texto enriquecido y herramientas de accesibilidad.

## 🛠️ Tecnologías utilizadas

El proyecto utiliza las siguientes librerías y herramientas:

- **Framework Core**: [Vue 3](https://vuejs.org/) (Composition API)
- **Runtime**: [Tauri v2](https://tauri.app/) (Rust para el backend, Webview para el frontend)
- **Estilos**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Gestión de Rutas**: [Vue Router](https://router.vuejs.org/)
- **Persistencia de Datos**: [IndexedDB (idb)](https://github.com/jakearchibald/idb)
- **Procesamiento de Markdown**: [Marked](https://marked.js.org/)
- **Animaciones**: [Motion-v](https://www.motion.dev/vue)
- **Accesibilidad**: [Text-to-Speech JS](https://www.npmjs.com/package/text-to-speech-js)
- **Herramientas de Construcción**: Vite & TypeScript

## ✨ Funcionalidades principales

- [x] **Gestión de Notas**: Creación y organización de notas en formatos `.txt` o `.md`.
- [x] **Gestión de Tareas**: Sistema completo para crear, editar y organizar tareas con diferentes niveles de prioridad.
- [x] **Perfil de Usuario**: Personalización de la experiencia con nombre de usuario, foto de perfil y fecha de nacimiento.
- [x] **Dashboard Dinámico**: Resumen visual de tareas y notas recientes para un acceso rápido a la información.
- [x] **Sistema de Etiquetas Centralizado**: Organización flexible compartida entre notas y tareas mediante etiquetas personalizadas.
- [x] **Filtrado Dinámico**: Búsqueda y filtrado eficiente basado en etiquetas, formatos o prioridades.
- [x] **Notas y Tareas Fijadas**: Capacidad de anclar elementos importantes para mantenerlos siempre visibles.
- [x] **Interfaz Adaptativa**: Diseño de rejilla responsivo con animaciones fluidas y transiciones suaves mediante Motion-v.
- [x] **Editor Markdown**: Interfaz de edición con previsualización en tiempo real para notas.
- [x] **Accesibilidad (TTS)**: Función integrada para leer el contenido de las notas en voz alta.
- [x] **Bienvenida Personalizada**: Sistema de bienvenida con saludos dinámicos basados en la información del usuario.
- [x] **Exportación**: Herramienta para exportar contenido de manera rápida a archivos locales.
- [x] **Barra de Herramientas**: Edición rápida con accesos directos para formato Markdown.
- [x] **Seguridad**: Restricciones para producción que evitan navegación no deseada y protegen la integridad de la app.
